


# 🚀 C# Tasks & Practice

## 📋 О проекте

Этот репозиторий содержит мои решения практических задач по языку **C#**. Здесь собраны упражнения, охватывающие различные темы: от базового синтаксиса до более сложных концепций ООП и работы с коллекциями.

Проект создан для:
- ✍️ Практики и закрепления теоретических знаний
- 📚 Демонстрации прогресса в изучении C#
- 🔄 Обмена опытом и получения обратной связи

---

## 🗂️ Структура проекта

Все задания разбиты на логические части для удобства навигации:

│   ├── Task1/
│   ├── Task2/
│   ├── ...

├── Tasks_part2/          # Часть 2: Продвинутые задачи

│   ├── Task2/
│   ├── ...
│   └── Task18/
│

│   ├── Task1/
│   ├── ...

> 💡 Каждая папка `TaskN` содержит отдельное решение с исходным кодом и, при необходимости, дополнительными файлами.

## 🛠️ Технологии и требования

Для запуска и проверки заданий вам понадобится:

| Инструмент | Версия |
|------------|--------|
| **.NET SDK** | 9.0 или выше |
| **IDE** | Visual Studio 2022 / Rider / VS Code |
| **Язык** | C# 10+ |

**Установка .NET SDK:**
```bash
# Проверка установленной версии
dotnet --version

# Если .NET не установлен, скачайте его с официального сайта:
# https://dotnet.microsoft.com/download
```

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Aziza-sh/c_sharp.git
cd c_sharp
```

### 2. Запуск конкретного задания

Перейдите в папку с нужной задачей и запустите проект:

```bash
cd Tasks_first_pr/Tasks_part1/Task1
dotnet run
```

> ⚠️ *Названия папок могут отличаться в зависимости от конкретного задания. Проверьте актуальный путь в вашем проводнике.*

### 3. Сборка всего решения (если есть .sln)

```bash
dotnet build
```
